# retired_scripts_manifest.txt — ownership data for aitask_prune_retired_skills.sh
#                                (invoked with --manifest <this file> --label script)
#
# Files the framework deleted or MOVED out of .aitask-scripts/ that installed
# projects must stop carrying, plus the set of git blob hashes the framework
# ever SHIPPED at those paths.
#
# WHY THIS EXISTS: install.sh extracts the release tarball over the project —
# purely additive — so a script the framework deleted or moved stays in every
# upgraded project, committed there by the framework-commit staging. A moved
# Python module is worse than dead weight: t1217 moved board/task_yaml.py to
# lib/task_yaml.py, aitask_board.py puts board/ ahead of lib/ on sys.path, and
# the stale copy shadowed its replacement and crashed every fresh `ait board`.
#
# WHY HASHES: an exact path is NOT proof of framework ownership — a user may have
# edited the file or kept their own at that name. The pruner deletes a file ONLY
# when `git hash-object <file>` appears in the SHA set below; anything else is
# preserved and reported. Release tarballs copy files verbatim and this repo has
# no .gitattributes (no CRLF/text filter), so an installed copy hashes
# identically to the blob it came from.
#
# FILE RECORDS ONLY — no DIR records. The pruner's DIR check is content-only
# against this flat SHA set, so a user file copied from a shipped blob into a
# retired directory would count as "known" and the whole directory would go.
# A FILE record removes only the historically shipped filename. The cost: an
# emptied directory (lib/attachment_backends/) is left behind — git does not
# track empty directories, so it is inert.
#
# NEVER LIST A PATH THE CURRENT RELEASE SHIPS. The prune runs after extraction;
# a listed live path would match its own (shipped) hash and be deleted from
# every project. tests/test_retired_scripts_manifest.sh enforces this, and also
# fails when a deleted/moved .aitask-scripts/ path is missing from this file.
#
# RECORD TYPES (tab-separated): FILE <path>, SHA <blob>.
#
# REGENERATE (run from the repo root after deleting or moving any file under
# .aitask-scripts/; `-m` covers merges, `--no-renames` makes a move show as a
# delete so the source path and its last blob are both kept):
#
#   PATHS=$(comm -23 \
#       <(git log -m --format= --name-only --diff-filter=A -- .aitask-scripts/ | sort -u) \
#       <(git ls-files .aitask-scripts/ | sort -u) | grep -v __pycache__)
#   for p in $PATHS; do printf 'FILE\t%s\n' "$p"; done
#   git log -m --no-renames --raw --no-abbrev --format= -- $PATHS \
#       | awk '{print $3; print $4}' | grep -v '^0\{40\}$' | sort -u \
#       | sed 's/^/SHA\t/'
#

# -> lib/).
