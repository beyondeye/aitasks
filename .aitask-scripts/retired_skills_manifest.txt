# retired_skills_manifest.txt — ownership data for aitask_prune_retired_skills.sh
#
# Retired skill surfaces that installed projects must stop carrying, plus the
# set of git blob hashes the framework ever SHIPPED at those paths.
#
# WHY HASHES: install_skills() / setup_codex() / setup_opencode() are additive
# `cp` loops — they never remove a wrapper that disappeared upstream, so an
# upgraded project keeps the retired files. But an exact path is NOT proof of
# framework ownership: a user may have customized the skill, kept their own
# unrelated skill at that name, or edited an untracked staging wrapper. The
# pruner therefore deletes a file ONLY when `git hash-object <file>` appears in
# the records below; anything else is preserved and reported. Release tarballs
# copy files verbatim and this repo has no .gitattributes (no CRLF/text filter),
# so an installed copy hashes identically to the blob it came from.
#
# DIR OWNERSHIP IS PER PATH, NOT JUST PER CONTENT. A file inside a retired DIR is
# known only when its exact (shipped path, blob) pair is a DIRSHA record — a
# user file copied byte-for-byte from a shipped blob, under a name that never
# shipped there, keeps the whole directory. The agent root is part of the key:
# .claude/skills/aitask-pickn shipped SKILL.md.j2, .agents/ and .opencode/ never
# did, so a copy of it under .agents/ is not framework-owned.
#
# STAGING ALIASES. The untracked staging dirs under aitasks/metadata/ never
# appear in git history; their DIR record names the directory they are a
# verbatim copy of, and ownership is looked up there. Each alias is proven by
# release packaging: .github/workflows/release.yml builds codex_skills/<s> with
# `cp -r .agents/skills/<s>` and opencode_skills/<s> with
# `cp -r .opencode/skills/<s>`, and install.sh copies both verbatim into
# aitasks/metadata/. Never add an alias without equivalent packaging proof.
#
# The SHA set is FLAT and governs FILE records only (a FILE record is already
# the exact path; the flat set also covers the opencode_commands/ staging copy).
#
# RECORD TYPES (tab-separated):
#   DIR <path> [<source>]  retired directory — removed all-or-nothing (every file
#                          <path>/<rel> must have a DIRSHA <source>/<rel> record
#                          for its blob). <source> defaults to <path>. A DIR
#                          holding any file with no matching DIRSHA record is
#                          kept; a DIR with no files at all (empty, or only
#                          empty subdirectories) has nothing to own and is
#                          removed whatever the DIRSHA records say.
#   DIRSHA <path> <blob>   a blob the framework shipped at exactly <path>
#   FILE <path>   retired single file — removed when its hash matches a SHA
#   STEM <name>   rendered-closure stem — matched EXACTLY against
#                 <root>/<stem>-<profile>[-<agent>]- dirs. Never prefix-globbed:
#                 the required hyphen after the stem is what stops a retired
#                 stem that is a PREFIX of a live skill from swallowing that
#                 skill's renders (retiring `aitask-pick` must not delete
#                 `aitask-pickn-fast-`).
#                 Closures are NEVER removed by an upgrade (their content is a
#                 function of the user's own profiles, so ownership cannot be
#                 proven); they are reported, and removed only under the
#                 explicit --prune-rendered flag.
#
# REGENERATE (run from the repo root; the prefixes are the authoring surfaces
# that were deleted — history still holds every version they shipped in).
#
# DIRSHA records (`-m` covers merge-side versions, `--no-renames` keeps each
# path's own blobs):
#
#   DIRS=".claude/skills/aitask-pickn .claude/skills/task-workflown \
#         .agents/skills/aitask-pickn .opencode/skills/aitask-pickn"
#   git log --all -m --no-renames --raw --no-abbrev --format= -- $DIRS \
#     | awk -F'\t' '{split($1,a," "); print a[3]"\t"$2; print a[4]"\t"$2}' \
#     | grep -v '^0\{40\}' | sort -u \
#     | awk -F'\t' '{print "DIRSHA\t"$2"\t"$1}' | sort
#
# SHA records:
#
#   PFX=".claude/skills/aitask-pickn .claude/skills/task-workflown \
#        .agents/skills/aitask-pickn .opencode/skills/aitask-pickn \
#        .opencode/commands/aitask-pickn.md"
#   git log --all --pretty=format:%H -- $PFX | while read -r c; do
#       git ls-tree -r "$c" -- $PFX 2>/dev/null | awk '{print $3}'
#   done | sort -u
#
