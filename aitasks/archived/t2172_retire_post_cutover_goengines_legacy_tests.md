## Context

Since the aitasks_go#t22 cutover, `goengines/` here is generated by export from
the private `beyondeye/aitasks_go` repository (nested `goengines/` module), and
`.github/workflows/goengines-check.yml` runs in export mode: `check` and
`bench` are skipped, only `export-integrity` runs. aitasks_go#t22_5 (commit
aitasks_go@a0515af) added the private CI that replaces the legacy jobs:

- private `.github/workflows/goengines.yml` (check + advisory bench);
- private ports of the script tests: `goengines/ci/tests/test_build.sh`,
  `test_benchci.sh`, `test_dashcheck.sh` (with `goengines/ci/tests/lib.sh`);
- private `goengines/ci/dashcheck.sh` now mounts the repository root (the
  public copy no longer ships `ci/` at all);
- private `goengines/README.md` now carries Layout, Build/test/bench, Dash
  parity, Host normalization, Rules for engine submodules, **Interfaces** and
  **Evidence contract (M3.2)**, and declares itself canonical (the exporter
  never writes the public README).
