Turn public `goengines/` into the **export target** for Go source developed in
the private `aitasks_go` repository, without disturbing today's pipeline
until the cutover. Decision record: `aidocs/aitasks_go/ship_path.md` in
aitasks_go (aitasks_go#t15). This task carries the parts of it that matter here.

## Policy (decided in aitasks_go#t15)

- The private `aitasks_go` repository is the single development home for every
  framework Go binary: `ait-testmap`, `ait-tui` (multi-app Bubble Tea binary)
  and `ait-monitord`.
- Ready, reviewed source snapshots are **exported** (copied, with import paths
  rewritten) into public `goengines/`, which builds and releases them. The
  public export is never the development source.
- Public holds only the source needed to compile: no `_test.go`, `testdata/`,
  `bench/` or `ci/` after the cutover. Tests, benches and the hang-guard
  preflight run privately at the exported commit, and their results are
  recorded in `goengines/EXPORT.txt`.
- Each export commit carries `Exported-From: beyondeye/aitasks_go@<sha>`. The
  testmap cutover (bootstrap export, aitasks_go migration task) also records
  `Migrated-From: beyondeye/aitasks@<sha>`.
- The migration of testmap development is scheduled separately (an aitasks_go
  task). **Until the cutover, testmap development continues here unchanged.**

## Work

1. **Two-mode CI keyed on one signal: whether `goengines/EXPORT.txt` exists.**
   - Legacy mode (no `EXPORT.txt`): `goengines-check.yml` and the
     `release.yml` goengines job run **exactly as today and stay required**
     (gofmt, vet, `ci/preflight.sh`, `go test`, the bench step). A new
     export-integrity job does nothing and reports that it is in legacy mode.
   - Export mode (`EXPORT.txt` present):
     - the export-integrity job is **required**: a script running the checks
       below, plus gofmt/vet/`go build ./...`;
     - the `EXPORT.txt` per-file sha256 comparison is a **non-blocking
       warning** that names drifted files (an emergency public fix not yet
       returned to aitasks_go);
     - `go test`, preflight and bench are skipped;
     - `release.yml` keeps `build.sh all` + `sha256sum -c` and adds the
       integrity script.
   - Activation happens in the bootstrap export commit itself, so there is
     never a window where neither validation is required. Tests cover both
     modes.
2. **Integrity script checks** (they mirror the exporter's own checks):
   - **No private dependencies.** This checks the module graph and imports,
     not free text:
     - `go.mod` has no `require`/`replace` naming a
       `github.com/beyondeye/aitasks_go` module, and no `replace` to a path
       outside the tree;
     - `go.sum` and `go list -m all` contain no such module;
     - no package import list contains such a path
       (`go list -deps -f '{{.ImportPath}}: {{join .Imports " "}}' ./...`).

     Provenance labels are explicitly allowed: the
     `// Code generated by aitasks_go export from <sha>; DO NOT EDIT.` headers,
     `EXPORT.txt`, commit trailers, and the `ait-tui version` `SOURCE:`
     constant.
   - **Independent build:** `GOWORK=off GOFLAGS=-mod=mod GOPRIVATE= GONOPROXY= GONOSUMDB= GOPROXY=https://proxy.golang.org`,
     then `go mod tidy -diff` clean and `go build ./...`.
   - **Per-binary dependency closure:** `go list -deps ./cmd/ait-testmap` (and
     `./cmd/ait-monitord` once present) ⊆ the testmap allowlist (yaml.v3,
     doublestar, x/sync). The testmap closure contains no `tui/` or Charm
     package. This restates `TestDependencyAllowlist` for a module that will
     also hold `ait-tui`.
3. **Docs:**
   - rewrite `goengines/README.md`: the tree is generated from aitasks_go, do
     not edit; the public-maintained files are only `README.md` and
     `.gitignore`;
   - document the **emergency-fix protocol**: a fix committed here carries the
     trailer `Return-To: aitasks_go`, and the same session creates a return
     task in aitasks_go (`ait create --batch --project aitasks_go`) naming the
     public commit. The next export refuses until the fix is ported back
     (`--drift-returned-in`);
   - amend `aidocs/framework/go_engine.md` and
     `aidocs/testing_engine/n014_explorer_006_proposal.md` (M1.2: the
     development location; the dependency allowlist scoped to the ait-testmap
     closure, plus a separate TUI allowlist; the scheduled cutover).

## Not in this task

- The export itself.
- Moving any source.
- Installer and launcher changes (separate aitasks task: ait-tui install +
  `AIT_GO_TUI` routing).

- The integrity script refuses a planted private import and a planted
