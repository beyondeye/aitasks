# t1954 parser research — harness, corpus and evidence

Research infrastructure for **t1954** (sustainable multi-language annotation
reading and safe editing for `ait test` / testmap). It scores candidate
lexical **providers** against the landed M2.2 baseline (`annot`, t1853_2)
**through the real grammar and rewriter**. Every record, placement, refusal
and write comes from the pinned `annot` snapshot. Nothing is re-implemented.

The design every t1954 child follows is the *Shared design* in
`aiplans/p1954_research_multilanguage_annotation_parsers.md` (or its archived
copy): layout, immutable baseline, evaluation seam, experimental interface,
oracle formats, metrics and measurement rules. This directory was built by
t1954_1; t1954_2/3 add providers and cases; t1954_4 writes the report
`aidocs/testing_engine/t1954_annotation_parser_research.md`.

## Layout

| path | what |
|---|---|
| `baseline/PIN` | the pinned commit, its `goengines` tree id, and the sha256 of `seam.patch` (committed) |
| `baseline/fetch.sh` | `git archive <commit> goengines` → `.baseline/` (patched) or `.baseline-unpatched/`, with every identity checked |
| `baseline/seam.patch` | adds exactly two nil-by-default hooks to the snapshot's `annot`: `ClassifyHook` (in `Classify`) and `LangHook` (in `LangOf`) |
| `go.mod` / `go.unpatched.mod` | this module (`…/goengines/t1954research`, so Go's import-path-based `internal` rule admits `internal/testmap/annot`), replacing `goengines` with `.baseline/` / `.baseline-unpatched/`, **never** the live checkout |
| `provider/` | the experimental interface (`provider.go`), the shared adapter `ToContext` with per-operation capability enforcement (`adapter.go`), research languages (`langs.go`), proposed placement rules (`placement.go`), and the providers `goscanner`, `pytokenize`, `shfmt` |
| `internal/` | `seam` (the only code touching the hooks), `identity`, `corpus` (oracle parsers, record flattening), `runner` (all levels), `oracle` (native comment ranges), `report` |
| `cmd/t1954/` | the verbs (below) |
| `oracle/` | `py_oracle.py` (Python `tokenize` + `ast`), `ts_oracle.js` (parser-aware TypeScript extraction, with `--selftest`) |
| `corpus/<lang>/<case>.<ext>.in` + `.expect` (+ `.edits`) | 213 fixtures in 8 languages; generated by `corpus/gen/gen_corpus.py` from the pinned M2.2 fixtures (`m22.py`) and the hand oracles (`hand_<lang>.py`) |
| `feasibility/functional_probes.sh` | the candidate compile/parse probes |
| `results/` | committed evidence (matrices, guard, oracle check, real-repository disagreement, bench, footprint, feasibility, environment) |
| `findings_t1954_1.md` | t1954_1's observations, documentation claims, assumptions and unknowns |

## Rerun

Every verb first checks `.baseline/IDENTITY` against `baseline/PIN`: commit,
tree, seam sha256, and a `content_sha256` over every snapshot file. It also
checks that the binary was built against that snapshot (build info). On any
mismatch, or a missing snapshot, it exits **2** and never falls back to the
checkout. The identity is printed at the top of every result.

```bash
cd aidocs/testing_engine/t1954_parser_research
baseline/fetch.sh && baseline/fetch.sh --unpatched
go vet ./... && go test ./...
go run ./cmd/t1954 guard --out results/guard.md   # seam neutrality
go run ./cmd/t1954 matrix                          # results/matrix*.md
go run ./cmd/t1954 oraclecheck                     # results/oracle_check.md
go run ./cmd/t1954 realrepo --repo "$(cd ../../.. && ./ait projects resolve aitasks | sed -n 's/^RESOLVED://p')" --name aitasks
go run ./cmd/t1954 bench                           # results/bench.md (idle host; several minutes)
go run ./cmd/t1954 footprint                       # results/footprint.md
go run ./cmd/t1954 env                             # results/environment.md
python3 corpus/gen/gen_corpus.py                   # regenerate the corpus (then rerun the above)
```

Other verbs:
- `edit [--provider p] [--lang l]`: the edit suite alone, to stdout.
- `classes --provider a,b <file>…`: line classes, for debugging.

`realrepo` reads sibling repositories **read-only**: it lists their
git-visible files and reports counts and paths, never contents. Nothing
there is executed. The other names are `aitasks_go`, `aitasks_mobile`,
`thinking_app`, `thinking_backend` and `timexchange`.

Optional native tools are looked up from the environment, all installed into
a scratch directory and never system-wide:
- `T1954_TS_NODE_MODULES`: a `node_modules` holding `typescript`, e.g.
  `npm install typescript@5.9.3`;
- `T1954_KOTLINC`: the kotlinc release zip, run on a local JDK;
- `T1954_SWIFT_DOCKER`: e.g. `swift:6.2`;
- `T1954_PYTHON`: default `python3`.

`bash`, `go`, `node`, `javac`/`java` and `rustc` come from `PATH`. A missing
tool shows up in the results as `none` / `not measured`, never as a pass.

### Moving the pin

Edit `baseline/PIN`:
- `commit:` the new commit;
- `tree:` from `git rev-parse <commit>:goengines`;
- `seam_sha256:` the patch's sha256, if the patch had to change.

Then run `baseline/fetch.sh && baseline/fetch.sh --unpatched` and commit the
PIN edit with the regenerated results. t1954_4's post-phase reports the old
and new pins side by side.

After any `go.mod` / `go.sum` change, regenerate the guard build's files. The
guard refuses to run until you do:

```bash
sed 's#./.baseline/goengines#./.baseline-unpatched/goengines#' go.mod > go.unpatched.mod && cp go.sum go.unpatched.sum
```

## Adding a provider (t1954_2 / t1954_3)

Implement `provider.Provider` in `provider/<name>.go` and `register` it. Declare
`Capabilities` honestly:
- `Anchors` lists only the anchors the provider **determines**; an undeclared
  anchor is unknown, never "none".
- `Errors` only when malformed input really yields `Diags`.
- `DocLiterals` only when it fills `Result.Doc` for Python.

`ToContext` enforces the rest per operation, and a missing capability is
reported `unsupported:<cap>` for that operation only:
- every write needs `Errors` (and `DocLiterals` for Python);
- only a fresh file-level insertion needs the per-language anchors.

Then run `matrix`, `realrepo`, `bench` and `footprint`. A provider that needs
cgo goes behind its own build tag, so the default build stays `CGO_ENABLED=0`.

## Adding fixtures

Add an `Fx` to `corpus/gen/hand_<lang>.py`. Mark every line that mentions the
token (the generator refuses one left unmarked):
- `⟦W⟧` writable annotation;
- `⟦L⟧` look-alike data;
- `⟦R⟧` read-only docstring line, with its decoded record in `docrecs`;
- `⟦C⟧` plain comment.

Give edits as explicit expected changes, then run
`python3 corpus/gen/gen_corpus.py` and `oraclecheck`. A disagreement with a
native tool is resolved in favour of the tool, or explained in the fixture
with these keys:
- `x-native-differs`;
- `x-policy`: a real comment that M2.2's policy never treats as an
  annotation line, reported as a policy divergence, not FP-writable.

## Isolation (pre-phase `scoped_commits_packaging_check`)

Nothing ships, builds or tests this directory:
- **Release tarball:** `.github/workflows/release.yml:133-142` lists
  `ait CHANGELOG.md .aitask-scripts/ packaging/ skills/ seed/ codex_skills/ opencode_skills/ opencode_commands/`,
  with no `aidocs/`. `install.sh` and `aitask_setup.sh` install from that
  tarball.
- **Go CI:** `.github/workflows/goengines-check.yml:9-23` triggers on
  `goengines/**` and named files only. Its gofmt / vet / test / cross-build
  steps run with `working-directory: goengines` (`:44`), whose `./...` never
  reaches a separate module under `aidocs/`.
- **Python tests:** `tests/run_all_python_tests.sh:174,224` discover
  `tests/test_*.py` only. The harness's Python file is
  `oracle/py_oracle.py`.
- **Shell lint:** the shellcheck targets are `.aitask-scripts/aitask_*.sh`
  (CLAUDE.md) and named scripts in `tests/`.
- **`tests/test_guard_contract_doc_drift.sh:52`** greps `aidocs/` for fixed
  banned phrases. The corpus contains none of them, and that test passes
  with this directory present.
- **testmap scans:** corpus fixtures carry the `.in` suffix (M2.2's
  convention), so no language table claims them. The extracted snapshots
  (`.baseline*/`) are git-ignored, and a scan lists git-visible files only.
- **Commits:** every commit of this work names its paths explicitly. Nothing
  under `goengines/` is modified.
